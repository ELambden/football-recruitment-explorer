Methodology Notes

Profiles are precomputed from StatsBomb Open Data. Radar values are role-aware percentiles, so a centre-forward and goalkeeper can both be displayed, but each is benchmarked against his own dominant position group. The Kane similarity rank is only calculated for the 47-player centre-forward cohort with 900+ minutes and 60%+ centre-forward minutes.
