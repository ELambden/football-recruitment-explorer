Method and limits

Profiles are precomputed from StatsBomb Open Data with exact lineup minutes, dominant position groups, per-90 event features, role-aware percentiles, robust-scaled similarity, bootstrap rank intervals, and feature-weight sensitivity checks.

Nearest profiles describe event-profile shape inside this historical sample. This is not a live transfer recommendation and does not include age, contract, wage, injury, scouting-video, or future-season information.
